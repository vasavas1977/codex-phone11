# PBX migration catalog corrections (source candidate, 2026-10-01)

These operator SQL files own `BEGIN`/`COMMIT` and must run standalone on a fresh idle connection. Never wrap them in an existing transaction or a migration runner that expects a later rollback: PostgreSQL ignores nested `BEGIN`, so the script's `COMMIT` could commit unrelated caller work. The defensive isolation checks do not make a READ COMMITTED wrapper safe; this invocation restriction remains an operator gate.
