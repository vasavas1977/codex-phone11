## Current official requirements

- New phone apps and updates must target **Android 16 / API 36** from 31 August 2026. The installed React Native 0.81.5 version catalog already specifies target/compile 36, minimum 24, AGP 8.11.0 and NDK 27.1.12297006. `app.config.ts` specifies minimum 24 and arm64/armeabi-v7a. This is dependency/config evidence; inspect the final AAB manifest to establish the actual target. No blind SDK bump is needed. [Google target API requirements](https://support.google.com/googleplay/android-developer/answer/11926878?hl=en)
- New Play apps use AAB and Play App Signing; the uploaded bundle must use the authorized upload key. [Android App Bundles](https://developer.android.com/guide/app-bundle), [app signing](https://developer.android.com/studio/publish/app-signing)
- Native libraries need 16 KB page-size compatibility. Inspect every packaged 64-bit native library and the delivered APK alignment, then run on a 16 KB device/emulator. The current Android documentation states an app-update enforcement date of 1 February 2027; do not repeat older deadlines without checking the app's current Play Console notice. SDK defaults alone do not establish compatibility. [Android 16 KB guide](https://developer.android.com/guide/practices/page-sizes)
- A public, working, non-PDF privacy policy is required in Play Console and in the app, covering actual data use, recipients, security, contact and retention/deletion practices. [User Data policy](https://support.google.com/googleplay/android-developer/answer/10144311?hl=en)
- Complete Data safety for actual first-party and SDK behavior. Service-provider transfers and intentional user sharing require classification against Google's definitions; a Google AI processor does not automatically mean all data is declared as third-party sharing. [Data safety guidance](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en)
- All developers answer deletion questions. The account-deletion flow requirement applies when the app creates accounts or sends users to an external creation flow. Current auth routes report `registrationEnabled:false` and the sign-in screen offers existing-account login. Determine the intended release provisioning flow before claiming an automatic violation or adding destructive account deletion. If creation is introduced, provide both in-app and external deletion-request paths. [Account deletion requirements](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en)
- Team Chat is UGC even within a company: users need content/user reporting; direct messaging needs blocking, with accepted usage terms and an operational response process. [UGC policy](https://support.google.com/googleplay/android-developer/answer/9876937?hl=en)
- Declare actual foreground-service types and provide the requested feature explanation/video. Declare full-screen intent if the final manifest uses it; calling functionality can qualify, but the grant must be checked and denial handled. Do not request restricted SMS/call-log access merely to show the app's own Recents. [Foreground services and full-screen intent](https://support.google.com/googleplay/android-developer/answer/13392821?hl=en), [permission declarations](https://support.google.com/googleplay/android-developer/answer/9214102?hl=en)
- New personal developer accounts created after 13 November 2023 generally need at least 12 closed-test participants continuously opted in for 14 days before applying for production access. Account type/status is unverified; this is conditional. [Testing requirements](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en-GB)
- Login-restricted apps need review access instructions. Store screenshots must depict the real app; provide at least two meeting the size constraints. Play's icon specification is 512×512. Developer identity, contact verification and applicable package-registration requirements must be checked in the actual account. [Review preparation](https://support.google.com/googleplay/android-developer/answer/9859455?hl=en), [preview assets](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en-GB), [developer identity](https://support.google.com/googleplay/android-developer/answer/10841920?hl=en)
