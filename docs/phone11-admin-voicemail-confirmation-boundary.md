# Admin voicemail confirmation boundary

The voicemail administration component reserves one confirmation/save synchronously. Native Alert callbacks are bound to the exact authenticated user object, selected workspace, component mount and page, and a snapshot of the extension identity, assignment, status, type and mailbox state. Before mutation and after each asynchronous completion it checks the current auth snapshot and the captured query's current row cache. A missing row/cache or failed current query refuses the action. Observed scope/row changes, Cancel, dismiss and unmount retire the retained confirmation; returning to the prior values does not revive it.

A current failure retains its error and permits an explicit fresh retry. A stale completion does not update the replacement UI or initiate invalidation there. Successful current saves invalidate only the captured workspace/page query. Already sent mutations cannot be canceled by this client guard: the existing server's fresh administrator checks remain the authority, and concurrent server row updates are not made transactional by this change. Mailbox enabling still does not prove inbox delivery, provider behavior or device acceptance.

Validation uses actual component rendering with persistent mocked hooks, native Alert callbacks, query cache and mutation promises. It covers workspace/session/unmount/row changes, synchronous duplicate suppression, cancel/dismiss, unchanged cache copies, stale success/failure/invalidation completion, current failure/retry and disabling an existing inactive mailbox. No server, database, provider or device action was performed.

Web uses an in-component React Native Modal because React Native Web's Alert does not present a confirmation. Enable only opens the dialog; its explicit Enable button sends the guarded mutation. Cancel, Modal request-close (including the web Escape handler) and dismissal release a pending confirmation without mutation. Other mailbox controls remain busy while confirmation or saving is current and unlock after cancellation or current completion. Native platforms retain the Alert path. The web regression tests exercise the actual component's Modal callbacks and require no Alert call; they preserve the native lifecycle cases.
