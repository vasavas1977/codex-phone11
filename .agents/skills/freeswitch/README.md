# FreeSWITCH Skill

Codex skill for FreeSWITCH work, backed by a markdown-only mirror of the SignalWire FreeSWITCH developer documentation.

## Install

```sh
npx skills add adinvadim/freeswitch-skill
```

## Reference Source

- Public docs: https://developer.signalwire.com/freeswitch/
- Source repo: https://github.com/signalwire/freeswitch-docs
- Local source metadata: `references/freeswitch-docs/SOURCE.md`

## Refresh Docs

```sh
./scripts/sync-freeswitch-docs.sh
```
